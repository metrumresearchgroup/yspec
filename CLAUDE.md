## What This Package Does

`yspec` is an R package for pharmacometrics data specification. It loads YAML files that define dataset column metadata, and uses those specs to generate FDA-compliant `define.pdf` documents, add factor columns, validate data, and provide plot axis labels. The core workflow: define columns once in YAML → load as R objects → generate regulatory docs and drive downstream R workflows.

## Common Commands

```bash
make doc          # Regenerate roxygen2 docs (run after editing @roxygen comments)
```

## Architecture

### Core Object Classes (S3)

- **`yspec`** — Main spec object (list of `ycol` objects + metadata). Represents one dataset. Key attributes: `sponsor`, `projectnumber`, `namespace`, `flags`, `glue`.
- **`ycol`** — Single column spec with fields: `col`, `type`, `short`, `label`, `unit`, `range`, `values`, `decode`, `discrete`, `namespace`.
- **`yproj`** — Collection of `yspec` objects for multi-dataset regulatory documents.

### YAML Spec Format

The `SETUP__` block contains dataset-level metadata. Columns are defined by name with optional fields. Special features:

```yaml
SETUP__:
  description: Example dataset
  sponsor: example-project
  projectnumber: EXAMPK1011F
  use_internal_db: true          # use built-in column database
  lookup_file: "look.yml"        # external shared column definitions
  extend_file: "analysis1-ext.yml"
  glue:                          # template variables (<<var>> syntax)
    bmiunits: "kg/m$^2$"
  flags:                         # column grouping for ys_filter()
    covariate: [AGE, WT, HT]
    nm: [ID, TIME, CMT, AMT, MDV]

TIME: !look                      # !look: pull from lookup_file or internal db
  label: time after first dose
  unit: hour

WT:
  unit.tex: "\\mu g/L"           # namespace: field.namespace dot notation
  dots: {time_varying: true}     # arbitrary metadata passthrough

BLQ:
  values: [0, 1]                 # categorical levels
  decode: [above QL, below QL]   # human-readable labels for values
  make_factor: true
```

**Special YAML tags**: `!look` (pull from lookup/internal db), `!decode` (inline value-decode pairs)

**Namespaces**: `field.namespace` pattern (e.g., `unit.tex`, `label.html`) — accessed via `ys_namespace(spec, "tex")`

### Test Data

Test specs live in `inst/spec/` (example YAML specs) and `inst/internal/` (internal examples used in vignettes/tests). Test data is generated by `inst/test_data/data.R` (run via `make data`). RMarkdown templates for define.pdf rendering are in `inst/rmd/`.
